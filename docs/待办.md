# 待办模块

桌面助手的待办事项管理，含待办窗口、SQLite 持久化、MCP 工具暴露。

## 涉及文件

| 文件 | 作用 |
|---|---|
| `Windows/Todo/TodoWindow.xaml(.cs)` | 待办主窗口（输入、列表、麦克风） |
| `Services/Data/TodoRepository.cs` | SQLite 待办仓储 |
| `Services/MCP/LocalTodoMcpServer.cs` | 把 TodoRepository 暴露为 MCP 工具 |
| `Models/TodoItem.cs` | 待办项模型（含 INotifyPropertyChanged） |

## 待办窗口（TodoWindow）

与聊天窗口**配色风格统一**（同样支持 `ApplyTheme(role)`）。

### 功能

- 输入回车或点「添加」新增待办
- **★ 输入区含 🎤 麦克风按钮**：语音输入待办内容（用法同聊天窗口）
- **双击列表项切换完成状态**：完成的项视觉上变灰
- 选中后点「删除选中」删除单条
- 点「清除已完成」一键清理所有已完成项
- 标题栏可拖动；点 ✕ 隐藏（不销毁，便于反复打开）
- 打开时自动从仓储刷新（AI 通过 MCP 修改数据后能立刻看到）
- 所有操作均写入日志

### 好感度联动（P9）

**完成待办 +2 好感度**（仅切换到"完成"时奖励，取消完成不扣）：
- `AffinityService.AddAffinity(role, +2, applySatietyBonus: true)`
- 饱食度>80 时 ×1.2 加成

详见 [助手管理数据库.md](助手管理数据库.md) 的好感度部分。

## 待办数据库（todo.db）

基于 SQLite 的待办仓储，**按用户隔离**（`user_data/users/<name>/todo.db`）。

### 表结构

#### Todo（待办项）

| 字段 | 类型 | 说明 |
|---|---|---|
| `Id` | INTEGER PK | 待办 ID（自增） |
| `Content` | TEXT | 待办内容 |
| `CreatedAt` | TEXT | 创建时间（ISO 8601） |
| `UpdatedAt` | TEXT | 最后更新时间（ISO 8601） |
| `IsDone` | INTEGER | 完成状态（0=未完成，1=已完成） |

### TodoRepository 方法

| 方法 | 用途 |
|---|---|
| `Add(content)` | 新增待办，返回带 Id 的 TodoItem |
| `Update(item)` | 更新待办（Content / UpdatedAt / IsDone） |
| `Delete(id)` | 删除指定 ID 的待办 |
| `ClearDone()` | 删除所有已完成项（`DELETE FROM Todo WHERE IsDone = 1`） |
| `ListAll()` | 列出所有待办（按 Id 升序） |
| `ListPending()` | 列出未完成待办 |
| `ListDone()` | 列出已完成待办 |

## MCP 工具暴露（LocalTodoMcpServer）

`LocalTodoMcpServer` 实现 `IMcpServer`，把 `TodoRepository` 暴露为 4 个 MCP 工具，让 AI 通过工具调用管理待办：

| 工具名 | 参数 | 返回 | 说明 |
|---|---|---|---|
| `todo_list` | 无 | 待办列表（Id/Content/IsDone/CreatedAt） | 列出所有待办 |
| `todo_add` | `content: string` | 新建待办的 Id | 添加待办 |
| `todo_complete` | `id: int` | 成功/失败 | 标记完成 |
| `todo_delete` | `id: int` | 成功/失败 | 删除待办 |

AI 调用示例：用户在聊天窗说"帮我加个待办：明天买牛奶"→ ChatOrchestrator 调用 `todo_add` → 待办入库 → TodoWindow 下次打开时可见。

## 数据流

```
用户在 TodoWindow 双击待办
  ↓
TodoItem.IsDone = !IsDone
  ↓
App.Todos.Update(item)  →  user_data/users/<name>/todo.db
  ↓
若 IsDone=true：AffinityService.AddAffinity(+2)  →  profile.yaml

AI 在聊天中说"帮我完成待办 #3"
  ↓
ChatOrchestrator 检测到工具调用
  ↓
McpManager.InvokeToolAsync("todo_complete", {id: 3})
  ↓
LocalTodoMcpServer → App.Todos.Update(...)  →  todo.db
  ↓
（注意：AI 通过 MCP 完成待办不触发好感度+2，仅用户手动双击才奖励）
```

## 配置

待办模块无独立配置文件，使用全局的：
- 数据库路径：`user_data/users/<name>/todo.db`（由 `App.OnStartup` 初始化 `App.Todos`）
- 主题配色：从角色 `theme.yaml` 读取（与聊天窗共用）

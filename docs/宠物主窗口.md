# 宠物主窗口模块

桌面宠物的核心交互入口，含动画、拖拽、托盘、菜单、点击穿透、皮肤切换。

## 涉及文件

| 文件 | 作用 |
|---|---|
| `Windows/Pet/PetWindow.xaml(.cs)` | 宠物主窗口 |
| `Services/Core/AnimationService.cs` | 动作系统服务（独立于皮肤） |
| `Services/Core/AudioService.cs` | NAudio 音频服务 |
| `Generators/` | 程序化资源生成器（像素画 + BGM） |

## 窗口特性

- **透明置顶无边框**：`WindowStyle=None` + `AllowsTransparency=True` + `Background=Transparent` + `Topmost=True`
- **不在任务栏显示**：`ShowInTaskbar=False`
- **不可缩放**：`ResizeMode=NoResize`
- **像素完美渲染**：`BitmapScalingMode=NearestNeighbor` + `EdgeMode=Aliased`
- **基础尺寸**：300×300 × 缩放比例（默认 0.4 = 120×120 显示）

## 多角色系统

从 `characters.yaml` 的 `roles` 字段读取所有可用角色（中文名 → 英文目录名映射），托盘「人物」子菜单动态生成。

### 切换角色（Switch）

`PetWindow.Switch(name)`：
1. 从 `SkinService` 获取当前皮肤（用户上次装备的或默认皮肤）
2. **皮肤主题覆盖角色主题**：`_config.Themes[name] = skin.Theme`，让所有 `ApplyTheme` 自动跟随皮肤
3. 加载精灵图帧
4. 切换托盘图标
5. 播放当前皮肤的 BGM
6. 播放问候语音（根据系统时间）
7. 应用配色到聊天/待办/右键菜单
8. 即时保存配置（记录当前角色，下次启动恢复）

### 切换皮肤（SwitchSkin）

`PetWindow.SwitchSkin(skinId)`：
1. 检查皮肤存在性、角色匹配、是否已解锁
2. 加载新皮肤的精灵图帧
3. 皮肤主题覆盖角色主题
4. 播放新皮肤的 BGM
5. 应用配色到子窗口
6. 持久化当前皮肤（`SkinService.Equip`）

## 动画系统

### 精灵图模式（默认）

单张 `sheet.png` 按配置的 `sprite_cols × sprite_rows` 切分多帧。默认 2 帧（睁眼 / 眨眼），按"睁眼—眨眼"节律播放：睁眼帧持续 `blink_interval_ms`（默认 3000ms），眨眼帧持续 `frame_scale[0]`（默认 150ms）。切帧由 `CroppedBitmap` 完成。

### 多帧序列模式（兼容旧资源）

当角色目录下没有 `sheet.png` 时，自动扫描目录下所有 PNG（按文件名排序）循环播放。

### 程序化动画（在帧之上叠加）

通过 WPF `DoubleAnimation` 实现：
- **呼吸**：纵向缩放 1.0 ↔ 1.03，2 秒周期，`SineEase` 缓动（驱动 `BreathScale.ScaleY`）
- **漂浮**：Y 位移 0 ↔ -3px，与呼吸同步（驱动 `BobTranslate.Y`）
- **拖拽反应姿态**：拖拽时纵向拉伸至 1.08、横向收缩至 0.96；松手后平滑恢复

### 动作系统服务（AnimationService）

独立于皮肤，驱动 PetWindow 的动画目标。动作定义在 `config/animations.yaml`。

**状态驱动**：`SetState(PetState)` 根据宠物状态切换循环：
- `Idle`：idle + breath + float（默认）
- `Hungry`：饱食度低于阈值，持续闭眼
- `Sleep`：长时间无互动，持续闭眼

**一次性动作**：`Play(animationId)` 播放一次性动作（pat/highfive/feed），结束后自动回到当前状态循环。

### 互动反应动画（P8）

由 `InteractPanel` 或双击宠物触发：
- `PlayPatReaction()`：纵向压扁（0.92）后回弹（1.05）+ 向上轻跳 6px，180ms
- `PlayHighfiveReaction()`：横向晃动（1.0→1.08）+ 轻微放大（1.0→1.05），150ms

## 双击抚摸（P8）

`OnMouseLeftButtonDown` 检测 `e.ClickCount >= 2`：
1. 触发 `QuickPat()` → `InteractionService.Interact(role, "pat")`
2. 成功则播放 `PlayPatReaction()` 动画
3. 不进入拖拽状态（`e.Handled = true` 后 `return`）

## 拖拽（DPI 安全）

左键按住角色不透明像素即可拖动。采用**增量法 + `TransformFromDevice`**：
1. `OnMouseLeftButtonDown`：记录拖拽起点屏幕坐标（`PointToScreen`）与窗口原始 Left/Top
2. `OnMouseMove`：用两次 `PointToScreen` 的差值乘以 DPI 反变换矩阵换算回逻辑 DIP 再叠加
3. `OnMouseLeftButtonUp`：结束拖拽，恢复呼吸/漂浮动画

拖拽时进入拖拽反应姿态（纵向拉伸 1.08、横向收缩 0.96）。

聊天/待办/模型设置/宠物管理窗口的标题栏拖拽也用同一方法。

## 逐像素点击穿透

通过挂钩 `WM_NCHITTEST`，对当前帧的透明像素（alpha < 10）返回 `HTTRANSPARENT`：
- 缓存当前帧像素（`CacheFramePixels`，BGRA 格式）
- 命中测试时根据鼠标坐标查像素 alpha
- **右键按下时不穿透**（通过 `GetAsyncKeyState(VK_RBUTTON)` 检测），保证右键菜单在任何位置都能弹出

## 系统托盘（TaskbarIcon）

基于 `Hardcodet.NotifyIcon.Wpf`。

### 托盘菜单（右键托盘图标）

- **人物**：从 `roles` 配置动态生成，当前角色带 `～` 标记；点击切换角色
- **静音**：全局静音开关（**只保留在托盘菜单**）
- **显示**：恢复被隐藏的宠物，窗口超出工作区时自动拉回
- **退出**：退出应用

### 托盘图标

从皮肤目录加载 `icon.png`，回退到 `sheet.png` 首帧。

## 宠物右键菜单（窗口级 ContextMenu）

精简菜单：聊天 / 待办 / 宠物管理 / 隐藏 / 退出

- **聊天**：打开聊天窗口（`PositionNextToPet` 定位到宠物旁）
- **待办**：打开待办窗口
- **宠物管理**：打开宠物管理窗口（单例，重复点击聚焦）
- **隐藏**：让宠物变透明（不退出，可通过托盘「显示」恢复）
- **退出**：播放当前皮肤的 farewell 语音后退出

> 已移除「了解」与「静音」项；静音只保留在托盘菜单。

### 菜单主题跟随角色

右键菜单的背景色、边框、菜单项文字色、悬停高亮色均从角色主题读取。切换角色时 `ApplyContextMenuTheme` 重新注入 `MenuItem` 样式（路飞=黄棕、索隆=绿棕）。

## 子窗口定位

`PositionNextToPet(child, gap=12)`：
- 默认放在宠物右侧，gap 12px
- 右侧空间不足自动放左侧
- 钳制到工作区内（`SystemParameters.WorkArea`）

## 记住上次角色

`Switch()` 切换角色后即时调用 `ConfigService.Save(_config)`，将角色偏好持久化到 `user_data/users/<name>/profile.yaml`，下次启动自动恢复。

## 键盘快捷键

- `Ctrl+Q`：退出
- `Ctrl+=`：放大（`_scale += 0.01`）
- `Ctrl+-`：缩小（`_scale -= 0.01`）

## 时段问候

根据系统时间播放「早上好/中午好/晚上好」语音（从当前皮肤的 `audio` 配置获取文件路径，缺失则静默跳过）。

## 静音

`App.IsMuted` 全局静音开关：
- 静音时：`AudioService.StopBgm()` + `StopSounds()`，`TTSService` 不朗读
- 取消静音时：恢复当前皮肤 BGM

## 资源加载

### 角色目录

`App.GetRoleDir(roleName)` 返回 `<BaseDir>/<static_path>/<英文目录>`，如 `.../static/luffy`。

### 精灵图加载（LoadFrames）

1. 优先尝试 `<roleDir>/sheet.png`（精灵图模式）
2. 切分为 `sprite_cols × sprite_rows` 帧
3. 失败则扫描目录下所有 PNG（多帧序列模式）

### 资源目录结构（皮肤系统后）

```
static/<角色英文目录>/<皮肤ID>/
├── sheet.png        # 精灵图
├── icon.png         # 托盘图标
├── bgm.mp3/.wav     # 背景音乐
├── 早上好.mp3        # 问候语音（可选）
├── 中午好.mp3
├── 晚上好.mp3
├── 晚安.mp3         # 退出语音
└── eat.mp3          # 喂食音效（可选）
```

## 程序化资源生成器（Generators/）

> 详细使用手册见 [Generators/README.md](../Generators/README.md)。

生成器独立为根目录 `Generators/` 模块（命名空间 `DesktopPetCSharp.Generators`），与主应用逻辑解耦。

### LuffySpriteGenerator
- 单帧 32×32 像素，2 帧（睁眼 / 眨眼）横向排列，4 倍放大输出
- 像素画元素：草帽 + 红色帽带 + 黑发 + 肤色脸 + 眼睛 + 大笑嘴 + 红背心
- 同时生成单帧 `icon.png`

### ZoroSpriteGenerator
- 单帧 32×32 像素，2 帧
- 像素画元素：绿发 + 黑头巾 + 左眼疤 + 肤色脸 + 绿色腹卷 + 刀鞘

### PixelArtRenderer
- 通用渲染器：输入"字符网格 + 调色板 + 倍数"，输出 PNG sprite sheet
- 被 Luffy / Zoro 生成器共用，新增角色只需提供网格与调色板

### BgmGenerator
- 索隆的默认 BGM 生成器：NAudio `WaveFileWriter` 合成正弦波 + 谐波的武士风小调旋律
- 输出 `bgm.wav` 到角色目录；用户放入自己的 `bgm.mp3` 后会被优先使用

### App 启动时的资源生成

`App.OnStartup` 遍历 `characters.yaml` 的 `roles`，对每个角色调用 `SpriteGeneratorRegistry.EnsureGenerated`：
- 路飞：`LuffySpriteGenerator` 生成到 `static/luffy/classic/`
- 索隆：`ZoroSpriteGenerator` 生成到 `static/zoro/classic/`
- 同时生成 `icon.png` 与默认 BGM（索隆用 `BgmGenerator`；路飞静默等待用户放入 `bgm.mp3`）
- 若已存在则跳过，便于用户手动替换

# 日志模块

应用的全局日志系统，记录所有用户操作与系统事件，按天滚动，线程安全。

## 涉及文件

| 文件 | 作用 |
|---|---|
| `Services/Core/Logger.cs` | 日志服务（单例，文件写入 + 线程锁） |

## 日志位置

```
user_data/logs/app_YYYYMMDD.log
```

- 按天滚动：每天一个文件，文件名含日期（如 `app_20260707.log`）
- 全局共享：所有用户共用同一份日志（不按用户隔离）
- 自动创建目录：`Logger.Init` 时确保 `user_data/logs/` 存在

## 日志格式

每行一条记录：

```
[yyyy-MM-dd HH:mm:ss.fff] [LEVEL] [category] message
```

示例：
```
[2026-07-07 15:43:15.123] [INFO] [App] 应用启动，BaseDir=d:\code\study\helper\DesktopGent，UserDataDir=...
[2026-07-07 15:43:20.456] [INFO] [UI] 右键菜单：打开助手管理
[2026-07-07 15:44:30.222] [ERROR] [Talk] 处理消息失败 System.Net.Http.HttpRequestException: ...
```

## 日志级别

| 级别 | 用途 |
|---|---|
| `INFO` | 常规信息：启动/退出、用户操作、状态变化 |
| `WARN` | 警告：资源缺失、回退行为、未实现的接口 |
| `ERROR` | 错误：异常堆栈、操作失败 |

## 日志分类

| 分类 | 记录内容 |
|---|---|
| `App` | 应用启动/退出、BaseDir/UserDataDir、配置加载、角色扫描、AI/MCP 注册 |
| `Gent` | 助手窗口：角色切换、拖拽起止、缩放、帧加载 |
| `Talk` | 聊天：用户发送消息、AI 回复、TTS 朗读、好感度加成 |
| `Todo` | 待办：增删改、完成状态切换、好感度加成 |
| `Chat` | ChatOrchestrator：工具调用与返回 |
| `Audio` | 音频：BGM 播放/停止、音效、静音切换 |
| `UI` | 界面操作：菜单点击、按钮点击、窗口打开、快捷键 |
| `Tray` | 托盘：图标加载、菜单切换 |
| `Speech` | 语音识别：起止与结果 |
| `User` | 用户管理：创建/登录/登出 |
| `Affinity` | 好感度：变化、衰减结算 |
| `Feed` | 喂食：饱食度变化、购买食物、喂食结果 |
| `Interact` | 互动：抚摸/击掌/玩耍触发与冷却 |
| `Logger` | 日志系统自身 |

## 记录范围

所有用户操作均写入日志：

- **启动/退出**：应用启动参数、用户登录、退出方式
- **角色切换**：切换前后角色名、帧组数、缩放
- **缩放**：放大/缩小快捷键、新缩放值
- **拖拽**：起始坐标、落点坐标
- **菜单点击**：右键菜单/托盘菜单的每一项
- **快捷键**：Ctrl+Q / Ctrl+= / Ctrl+-
- **聊天消息**：用户发送内容、AI 回复内容
- **AI 工具调用**：工具名、参数、返回结果
- **待办操作**：增删改、完成状态切换
- **BGM 切换**：播放/停止、文件路径
- **配色应用**：角色主题、右键菜单主题
- **语音识别**：起止、识别结果
- **好感度变化**：增减值、变化前后、等级
- **喂食**：食物、偏好、饱食度变化、好感度加成
- **互动**：动作类型、好感度奖励、冷却拒绝

## 线程安全

`Logger` 内部用 `lock` 保护文件写入，多线程并发调用安全：
- `TalkWindow.ProcessAsync` 在后台线程调用 `Logger.Info`
- `AffinityService.DecayTick` 在 DispatcherTimer 线程调用
- `ChatOrchestrator` 在后台线程调用

## API

| 方法 | 级别 | 用途 |
|---|---|---|
| `Logger.Init(userdataDir)` | — | 初始化日志目录（应用启动时调用一次） |
| `Logger.Info(category, message)` | INFO | 记录信息 |
| `Logger.Warn(category, message)` | WARN | 记录警告 |
| `Logger.Error(category, message, exception?)` | ERROR | 记录错误（含异常堆栈） |

## 初始化时机

`App.OnStartup` 第一步（在所有其他操作之前）：

```csharp
Logger.Init(UserDataDir);
Logger.Info("App", $"应用启动，BaseDir={BaseDir}，UserDataDir={UserDataDir}");
```

确保后续所有操作都能被记录。

## 日志轮转

按天滚动：写入日志时检查当前日期，若与现有文件名日期不符则新建文件。无自动清理（用户可手动删除旧日志）。

## 隐私说明

日志可能含用户输入内容（聊天消息、待办内容），但：
- 不含 API_KEY（敏感信息只记录"已注册/跳过"等元信息）
- 不含密码（用户管理无密码字段）
- 日志文件在 `user_data/logs/`，已被 `.gitignore` 排除不入库

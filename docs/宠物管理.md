# 宠物管理模块

桌面宠物的经济与互动系统入口，含商店、互动、喂食、状态四个面板。从宠物右键菜单「宠物管理」打开。

## 涉及文件

| 文件 | 作用 |
|---|---|
| `Windows/PetManager/PetManagerWindow.xaml(.cs)` | 宠物管理主窗口（Tab 容器） |
| `Windows/PetManager/Panels/ShopPanel.cs` | 商店面板（皮肤购买/装备） |
| `Windows/PetManager/Panels/InteractPanel.cs` | 互动面板（抚摸/击掌/玩耍） |
| `Windows/PetManager/Panels/FeedPanel.cs` | 喂食面板（背包 + 喂食） |
| `Windows/PetManager/Panels/StatusPanel.cs` | 状态面板（好感度/饱食度/金币/皮肤总览） |
| `Services/Core/SkinService.cs` | 皮肤服务（加载/查询/装备/解锁/购买） |
| `Services/Core/AffinityService.cs` | 好感度服务（等级/增减/衰减后台计时器） |
| `Services/Core/FeedService.cs` | 喂食服务（饱食度/背包/喂食） |
| `Services/Core/InteractionService.cs` | 互动服务（冷却/好感度奖励） |

## 宠物管理窗口（PetManagerWindow）

560×600 无边框圆角窗口，主题跟随当前角色。顶部 4 个 Tab 按钮（商店/互动/喂食/状态），点击切换内容区。

### Tab 容器机制

- 4 个 Panel 懒加载：首次切换到某 Tab 时才实例化对应 Panel
- `IPetManagerPanel` 接口：`ApplyTheme(RoleTheme)` + `Refresh()`
- 切换 Tab 时调用 `ApplyTheme` 和 `Refresh` 同步主题与数据
- Tab 按钮配色：激活的用主色背景，其他用表面色

### 单例

PetManagerWindow 由 PetWindow 持有（`_petManager` 字段），重复点击右键菜单「宠物管理」会聚焦已有窗口而非新建。关闭后置 null，下次点击重新创建。

## 商店面板（ShopPanel）

皮肤购买与装备。

### 功能

- 顶部显示当前金币余额
- 列出所有皮肤（按角色分组），每个皮肤卡片显示：
  - 预览图（精灵图首帧）
  - 皮肤名称 + 所属角色
  - 价格（应用好感度等级折扣后的实际价格）
  - 状态标记（✓已解锁 / ✓当前装备 / 🔒未解锁）
  - 操作按钮（购买 / 装备）
- **购买确认对话框**：点击购买后弹出确认框，显示最终价格（含折扣）
- **装备切换**：已解锁的皮肤点「装备」立即切换，PetWindow 加载新皮肤的精灵图、BGM、主题

### 价格计算

- 基础价格：`PetManagementConfig.Constants.SkinPrice`（默认 400 金币，见 `config/pet_management.yaml`）
- 好感度折扣：根据当前角色好感度等级的 `SkinDiscount` 系数
  - 挚友（80+）：0.7（7 折）
  - 亲密（60+）：0.8（8 折）
  - 友好（40+）：0.9（9 折）
  - 认识（20+）：0.95（95 折）
  - 陌生人（0+）：1.0（无折扣）
- 最终价格 = `基础价格 × SkinDiscount`（向下取整）

### 购买流程

1. 检查金币是否足够（应用折扣后的价格）
2. 扣金币 → 解锁皮肤（加入 `UnlockedSkins`）→ 持久化 `profile.yaml`
3. 自动装备刚购买的皮肤

## 互动面板（InteractPanel）

抚摸/击掌/玩耍按钮 + 实时冷却显示。

### 互动类型

| 动作 | 好感度 | 冷却 | 状态 |
|---|---|---|---|
| pat（抚摸） | +1 | 5 秒 | ✅ 已实现 |
| highfive（击掌） | +2 | 30 秒 | ✅ 已实现 |
| play（玩耍） | — | 300 秒 | 🚧 预留（小游戏暂不实现） |

### 冷却机制

- 同种互动在冷却时间内重复触发会被拒绝，按钮禁用并显示剩余秒数
- 面板内置 1 秒刷新计时器（`DispatcherTimer`），实时更新冷却文本
- `play` 永远禁用（建设中），点击提示"敬请期待"

### 好感度加成

- 饱食度>80 时互动好感度 ×1.2（`Rewards.SatietyHighBonus`）
- 由 `AffinityService.AddAffinity(role, reward, applySatietyBonus: true)` 自动应用

### 动画联动

互动成功后联动 PetWindow 播放反应动画：
- 抚摸 → `PlayPatReaction()`：纵向压扁后回弹 + 向上轻跳 6px
- 击掌 → `PlayHighfiveReaction()`：横向晃动 + 轻微放大

### 双击宠物快速抚摸

PetWindow 的 `OnMouseLeftButtonDown` 检测 `e.ClickCount >= 2`，触发 `QuickPat()`：
1. 调用 `InteractionService.Interact(role, "pat")`
2. 成功则播放 `PlayPatReaction()` 动画
3. 不进入拖拽状态

## 喂食面板（FeedPanel）

背包食物网格 + 当前角色饱食度。

### 顶部饱食度显示

`🍖 {角色} 饱食度：{value}/100{status}`
- status：`⚠ 饥饿`（<20）/ `😋 饱腹`（>80）/ 空

### 背包食物列表

只显示背包中数量 > 0 的食物，每个食物卡片：
- 图标 + 名称
- 偏好标记（❤️ 喜欢 / 😐 普通 / 💔 讨厌）
- 饱食度增益（`+{satiety_gain}`）
- 数量（`×{count}`）
- 喂食按钮

### 喂食流程

1. 检查背包数量（`ConsumeInventory`）
2. 加饱食度（`AddSatiety`，上限 100）
3. 按偏好加好感度：
   - loved：+8（`Rewards.FeedLoved`）
   - normal：+5（`Rewards.FeedNormal`）
   - disliked：+1（`Rewards.FeedDisliked`）
4. 饱食度>80 时好感度 ×1.2 加成
5. 弹出结果对话框（含偏好描述与加成提示）

### 购买食物对话框

点「🛒 购买食物」打开模态对话框：
- 顶部显示当前金币
- 列出所有食物（图标 + 名称 + 价格）
- 点「购买×1」扣金币 + 入背包 + 刷新金币显示

## 状态面板（StatusPanel）

当前角色的好感度/饱食度/金币/已解锁皮肤总览。

### 内容分区

1. **📊 宠物状态总览**（标题）
2. **🎭 当前角色**：角色名 + 当前皮肤名
3. **💰 经济 & 状态**：
   - 金币余额
   - 好感度（含等级名与皮肤折扣百分比）
   - 饱食度（含饥饿/饱腹状态标记）
4. **👑 已解锁皮肤**：按角色分组列出所有皮肤
   - `✓当前`：当前装备
   - `✓`：已解锁
   - `🔒`：未解锁（显示价格）
   - 底部汇总：`共解锁 X / Y 个皮肤`
5. **🌟 好感度等级影响**：
   - 当前等级名 + 描述
   - 皮肤折扣系数（省 X%）
   - AI 对话风格提示

## 主题跟随

所有 Panel 实现 `IPetManagerPanel.ApplyTheme(RoleTheme)`：
- 边框背景色：`SurfaceColor` 半透明
- 边框色：`BorderColor`
- 文字色：`TextColor`
- 按钮背景：`PrimaryColor`，文字：`BackgroundColor`

切换角色或皮肤时，PetManagerWindow.ApplyTheme 会同步到所有已加载的 Panel。

## 数据持久化

宠物管理涉及的所有数据都存储在 `user_data/users/<name>/profile.yaml`，详见 [宠物管理数据库.md](宠物管理数据库.md)。

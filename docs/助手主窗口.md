# 助手主窗口

桌面助手的核心交互入口，负责角色资源加载、文件夹驱动动画、托盘与右键菜单、拖拽与双击、点击穿透。

对应代码：[Windows/Gent/GentWindow.xaml.cs](../Windows/Gent/GentWindow.xaml.cs)。

## 角色切换（Switch）

1. 根据当前角色英文目录计算 `_roleDir = App.GetRoleDir(name)`。
2. 调用 `LoadFrameSets()` 扫描子文件夹，`01_idle_breath/` 作为呼吸循环、`02_idle_nose_pick/` 作为随机动作。
3. 按呼吸帧长宽比设置窗口尺寸，启动呼吸循环与随机动作计时器。
4. 应用主题到聊天/待办窗口与右键菜单，保存角色偏好。

## 动画（文件夹驱动）

不再使用 `animations.yaml`。帧图直接放在角色目录子文件夹中：

```
static/<角色目录>/
├── 01_idle_breath/      # 原地呼吸循环（默认 idle）
└── 02_idle_nose_pick/   # 随机扣鼻孔（偶尔触发）
```

- `01_idle_breath/`：空闲时按 `frame_interval_ms`（默认 120ms）循环播放全部帧。
- `02_idle_nose_pick/`：按 `random_action_interval_ms`（默认 9s，带 ±20% 随机抖动）触发一次，播完回到呼吸。
- 窗口尺寸固定为呼吸帧的长宽比，所有帧用 `Uniform` 居中缩放，避免不同帧比例导致跳动。
- 喂食 / 抚摸 / 击掌等操作**只更新状态，不播放响应动画**。

## 托盘与右键菜单

- 托盘菜单：角色切换、静音、显示、设置（含导入助手角色）、退出。
- 右键菜单（窗口级）：聊天、待办、助手管理、隐藏、退出。
- 右键菜单主题从角色 `theme.yaml` 读取，禁止硬编码颜色。

## 鼠标交互

- 双击助手：触发抚摸（`InteractionService.Interact(role, "pat")`），只加好感度状态。
- 单击拖拽：使用 `PointToScreen(e.GetPosition(this))` 计算 DIP 增量，避免高 DPI 位置跳跃。
- 点击穿透：缓存当前帧 BGRA 像素，透明区域返回 `HTTRANSPARENT`；右键按下时保持右键菜单可弹出。

## 快捷键

- `Ctrl+Q`：退出。
- `Ctrl++` / `Ctrl+-`：放大 / 缩小显示（写入 `_config.FrameScale` 并保存角色偏好）。

## 退出

- 托盘或右键「退出」→ `Quit()`：保存配置、关闭聊天/待办、释放托盘图标、关闭窗口并 `Shutdown`。
- `OnClosed` 停止动画/随机计时器并再次释放托盘资源。

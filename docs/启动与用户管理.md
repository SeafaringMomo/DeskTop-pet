# 启动与用户管理

说明应用启动流程、用户创建/登录、多用户数据隔离与角色偏好恢复。

对应代码：[App.xaml.cs](../App.xaml.cs) 与 [Services/Core/UserService.cs](../Services/Core/UserService.cs)。

## 启动流程

`App.OnStartup` 顺序：

1. 单实例检测（Mutex），失败则提示并退出。
2. `Logger.Init(UserDataDir)`（最先执行）。
3. `RegisterAiProviders()`：从 `secrets.yaml` 注册，回退环境变量，兜底 `LocalKleeProvider`。
4. 显示启动页 `LauncherWindow`，用户选择/新建用户。
5. 用户未进入则退出。
6. `InvalidateCache()`：让后续 `Load()` 使用 `CurrentUser.Role`。
7. 按用户初始化 `todo.db` 与 `chat_history.db`，注册 MCP 服务器。
8. 创建并显示 `GentWindow` 主窗口（角色由配置/用户偏好决定）。
9. `ApplyPendingRole()`：应用启动前暂存的角色偏好。
10. `AffinityService.Instance.Start()`：启动衰减计时器。

## 用户目录结构

```
user_data/
├── users.yaml                    # 用户注册表
└── users/<name>/
    ├── profile.yaml              # 角色偏好、金币、好感度、饱食度、背包
    ├── todo.db
    └── chat_history.db
```

## 创建 / 登录用户

| 方法 | 说明 |
|---|---|
| `CreateUser(name)` | 初始化 profile 与数据目录，金币取 `InitialCoins` |
| `Login(name)` | 加载档案并更新最后登录时间 |
| `Logout()` | 清空当前用户 |
| `ListUsers()` | 按最后登录时间排序列出用户 |

新用户不再初始化皮肤（皮肤系统已移除）。

## 角色偏好

- 偏好存于 `profile.yaml` 的 `role` 字段。
- 未登录时暂存内存 `_pendingRole`，登录后 `ApplyPendingRole()` 写入档案。
- 启动恢复优先级：`CurrentUser.Role` > `_pendingRole` > 扫描到的第一个角色。

## 角色导入

位于 托盘菜单 → 设置 → 「导入助手角色」：

1. 选择包含 `theme.yaml` 的文件夹。
2. 复制到 `static/<文件夹名>/`（已存在则拒绝）。
3. `InvalidateCache()` 并回调 `GentWindow` 刷新角色菜单。

角色扫描规则与主题文件格式见 [docs/config配置.md](config配置.md)。

# 启动与用户管理模块

应用入口、启动页、多用户隔离管理。

## 涉及文件

| 文件 | 作用 |
|---|---|
| `App.xaml(.cs)` | 应用程序入口 |
| `Windows/Launcher/LauncherWindow.xaml(.cs)` | 启动页窗口 |
| `Services/Core/UserService.cs` | 用户管理服务（单例） |
| `Services/Core/ConfigService.cs` | 配置服务（缓存 + 加载） |
| `Models/UserProfile.cs` | 用户档案模型 |

## 应用入口（App）

`App.xaml.cs` 在 `OnStartup` 中按顺序完成：

1. **初始化日志系统**（最先执行）。日志位于 `user_data/logs/`。
2. **为所有配置的角色生成像素精灵图**：遍历 `characters.yaml` 的 `roles`，对每个角色调用 `SpriteGeneratorRegistry.EnsureGenerated`，生成到 `static/<角色>/classic/` 子目录。
3. **注册 AI 提供方**（`RegisterAiProviders`）：从 `config/secrets.yaml` 加载，回退到环境变量，兜底注册 `LocalKleeProvider`。
4. **显示启动页**（`LauncherWindow` 模态对话框）：用户在此新建/选择用户、配置模型、或退出。未登录关闭启动页则应用退出。
5. **用户登录后**：
   - 失效 `ConfigService` 缓存（让后续 `Load()` 用 `CurrentUser.Role` 覆盖默认角色）
   - 初始化 `TodoRepository`（`user_data/users/<name>/todo.db`）
   - 初始化 `ChatHistoryRepository`（`user_data/users/<name>/chat_history.db`）
6. **注册 MCP 服务器**（`RegisterMcpServers`）：从 `config/secrets.yaml` 加载；`type=local` 且 `name=local-todo` 时注册 `LocalTodoMcpServer`；`stdio/sse` 为预留接口；无配置时兜底注册 `local-todo`。
7. **启动 `PetWindow` 主窗口**（定位到主屏幕右下角，避免高 DPI 缩放下落屏外）。
8. **应用待处理角色偏好**：`UserService.ApplyPendingRole()`。
9. **启动好感度衰减后台计时器**：`AffinityService.Instance.Start()`。
10. **迁移清理**：删除旧版 `user_data/config_pet.yaml`（已被 `users/<name>/profile.yaml` 取代）。

### 启动模式

`App.xaml` 设置 `ShutdownMode=OnExplicitShutdown`，启动页是主窗口但关闭不会触发应用退出；用户登录后切换主窗口为 `PetWindow`，`PetWindow.OnClosed` 中调用 `Application.Current.Shutdown()` 兜底退出。

### App 静态属性

| 属性 | 说明 |
|---|---|
| `BaseDir` | 项目根（含 `.csproj` 的目录），优先环境变量 `DESKTOP_PET_BASE` |
| `UserDataDir` | 项目根 `user_data/` |
| `Todos` | 当前用户的待办仓储（登录后初始化） |
| `ChatHistory` | 当前用户的对话记录仓储（登录后初始化） |
| `IsMuted` | 全局静音开关 |
| `MainWindow` | 当前主窗口（启动页 → PetWindow） |

### App 静态方法

| 方法 | 用途 |
|---|---|
| `GetRoleDir(roleName)` | 返回 `<BaseDir>/<static_path>/<英文目录>` |
| `GetRoleFile(roleName, fileName)` | 返回角色目录下某文件的完整路径 |

## 启动页（LauncherWindow）

模态对话框，用户在此：
- **新建用户**：点「+ 新建用户」→ 输入用户名 → `UserService.CreateUser`（继承当前默认角色）→ 自动登录
- **选择用户**：双击用户列表项 → `UserService.Login` → 关闭启动页进入主界面
- **更换模型**：打开 `ModelSettingsWindow`（在登录前也可配置 AI provider）
- **退出**：直接关闭启动页 → `App.Shutdown()`

`Entered` 属性标记是否已登录进入主界面，`App.OnStartup` 据此决定是继续启动 `PetWindow` 还是退出。

启动页主题跟随默认角色（`ApplyTheme(role)`）。

## 用户管理（UserService）

单例服务（`UserService.Instance`），管理多用户隔离。

### 数据目录结构

```
user_data/
├── users.yaml                # 用户注册表（所有用户名 + 创建/最后登录时间）
└── users/
    └── <username>/
        ├── profile.yaml      # 用户档案（角色偏好、缩放、金币、皮肤、好感度、饱食度、背包）
        ├── chat_history.db   # 对话记录 SQLite（按用户隔离）
        └── todo.db           # 待办 SQLite（按用户隔离）
```

### 关键属性

| 属性 | 说明 |
|---|---|
| `CurrentUser` | 当前登录用户（`UserProfile?`，未登录为 null） |
| `CurrentUserName` | 当前登录用户名（便捷访问，未登录返回空串） |
| `CurrentUserDir` | 当前用户的数据目录（`user_data/users/<name>/`） |

### 关键方法

| 方法 | 用途 |
|---|---|
| `ListUsers()` | 列出所有已注册用户（按最后登录时间降序） |
| `CreateUser(name)` | 创建新用户（初始化 profile + 数据目录 + 默认皮肤） |
| `Login(name)` | 登录指定用户，加载其档案到 `CurrentUser` |
| `Logout()` | 登出当前用户 |
| `LoadProfile(name)` | 加载用户档案 |
| `SaveProfile(profile)` | 保存用户档案 |
| `SaveCurrentProfile()` | 保存当前登录用户的档案 |
| `SaveCurrentRole(role)` | 登录后写入 `profile.yaml`，未登录时记到 `_pendingRole` 内存 |
| `TryGetLastRole()` | 优先 `CurrentUser.Role`，其次 `_pendingRole` |
| `ApplyPendingRole()` | 登录后把待处理角色偏好应用到当前用户 |

### 创建新用户流程

`CreateUser(name)`：
1. 检查用户名是否已存在
2. 创建 `user_data/users/<name>/` 目录
3. 初始化 `UserProfile`：
   - `Name` = 用户名
   - `Role` = 当前默认角色（从 `ConfigService.Load().Role`）
   - `Scale` = 0.4
   - `DefaultProvider` = "local-klee"
   - `CreatedAt` / `LastLoginAt` = 当前时间
   - `Coins` = `pet_management.yaml` 的 `initial_coins`（默认 100）
4. `SkinService.InitDefaultSkins(profile)`：解锁所有 `is_default: true` 的皮肤并设为当前皮肤
5. 写入 `profile.yaml`
6. 加入 `users.yaml` 注册表

### 登录流程

`Login(name)`：
1. 从注册表查找用户
2. 加载 `profile.yaml`（若丢失用默认值重建）
3. 更新 `LastLoginAt` 并保存
4. 设置 `CurrentUser`
5. 返回用户档案

## 配置服务（ConfigService）

### 加载机制

`ConfigService.Load()` 合并 `app.yaml` + `characters.yaml` 为运行时 `PetConfig`：
1. 读 `app.yaml`（音频、精灵图、动画、窗口）
2. 读 `characters.yaml`（角色映射、配色、frame_scale）
3. 用 `UserService.TryGetLastRole()` 覆盖默认角色
4. 缓存结果（`lock` + 静态字段）

### 缓存失效

| 方法 | 何时调用 |
|---|---|
| `InvalidateCache()` | 用户登录后（让 `Load()` 用 `CurrentUser.Role` 覆盖） |
| `InvalidateSecretsCache()` | 模型设置窗口编辑 provider 后 |
| `InvalidatePetManagementCache()` | 宠物管理配置变更后 |

### 用户偏好持久化

角色偏好**不写入 `config/`**，而是由 `UserService.SaveCurrentRole` 写入 `user_data/users/<name>/profile.yaml`，按用户隔离。

### 向后兼容

- 无 `app.yaml` / `characters.yaml` 时回退到旧版 `config/config_pet.yaml`（已删除，仅留代码兜底）
- 旧版 `user_data/config_pet.yaml` 在用户首次登录成功后被 `App.CleanupLegacyUserConfig()` 自动清理（角色偏好已迁移到 `profile.yaml`）

## 模型设置窗口（ModelSettingsWindow）

从聊天窗口标题栏「⚙ 模型」按钮、或启动页「更换模型」按钮打开。

### 功能

- 列出所有已注册的 AI 提供方（来自 `AiProviderRegistry`），显示名称、是否支持工具调用、描述
- 显示当前默认提供方
- 选中后点「应用」切换默认提供方
- **增删改 provider**：底部 ➕ 新增 / ✏ 编辑 / 🗑 删除 三个按钮，编辑界面用 `PasswordBox` 输入 API_KEY
  - `local-klee` 为内置兜底，不可编辑/删除
  - 删除当前默认 provider 后自动回退到 `local-klee`
- **主题跟随角色**：`ApplyTheme(role)` 完整应用 RootBorder/TitleBar/按钮配色

变更即时写回 `config/secrets.yaml`，并同步 `AiProviderRegistry`。

## 数据流总览

```
应用启动
   ↓
Logger.Init → 生成精灵图 → RegisterAiProviders (从 secrets.yaml)
   ↓
LauncherWindow.ShowDialog (新建/选择用户、更换模型、退出)
   ↓ 登录成功
ConfigService.InvalidateCache → 初始化 Todo/ChatHistory (按用户隔离)
   ↓
RegisterMcpServers (从 secrets.yaml) → PetWindow.Show → AffinityService.Start
   ↓
CleanupLegacyUserConfig (删除旧版 config_pet.yaml)

用户输入
   ↓
TalkWindow → ChatOrchestrator
   ↓
AiProviderRegistry.Default (IAiProvider)
   ├─ LocalKleeProvider (本地占位，无工具调用)
   └─ OpenAiCompatibleProvider (HTTP, 支持工具调用)
        ↓ 工具调用请求
        McpManager.InvokeToolAsync
        └─ LocalTodoMcpServer (todo_list/add/complete/delete)
   ↓
每条消息 → ChatHistoryRepository.AddMessage → user_data/users/<name>/chat_history.db

资源加载：App.GetRoleDir(roleName) → static/<英文目录>/<皮肤>/
切换角色 → PetWindow.Switch() → 加载像素图 + 播放 BGM + ApplyTheme()
                → ConfigService.Save → UserService.SaveCurrentRole → profile.yaml
所有用户操作 → Logger → user_data/logs/app_YYYYMMDD.log
```

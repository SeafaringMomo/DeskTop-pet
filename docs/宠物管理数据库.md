# 宠物管理数据库

宠物管理系统的数据存储说明，包含用户皮肤数量、食物储备、金币数量、宠物状态、宠物好感度等字段。

## 数据存储位置

```
user_data/
├── users.yaml                  # 用户注册表（所有用户名 + 创建/最后登录时间）
└── users/
    └── <username>/
        ├── profile.yaml        # ★ 用户档案（宠物管理数据全部存于此）
        ├── chat_history.db     # 对话记录 SQLite（详见聊天.md）
        └── todo.db             # 待办 SQLite（详见待办.md）
```

**核心结论**：宠物管理数据（金币/皮肤/好感度/饱食度/背包）**不存数据库**，而是存在 `profile.yaml`（YAML 文本文件），便于用户查看与备份。对话与待办才用 SQLite。

## profile.yaml 字段说明

对应 `Models/UserProfile.cs`，分 5 组：

### 1. 基础信息

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `name` | string | "" | 用户名（唯一标识） |
| `role` | string | "路飞" | 当前角色（中文） |
| `scale` | double | 0.4 | 当前缩放比例 |
| `default_provider` | string | "local-klee" | 默认 AI 提供方名 |
| `created_at` | string | "" | 创建时间（ISO 8601） |
| `last_login_at` | string | "" | 最后登录时间（ISO 8601） |

### 2. 经济系统

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `coins` | int | 100 | **金币余额**（新用户初始 100，见 `pet_management.yaml` 的 `initial_coins`） |
| `unlocked_skins` | list<string> | [] | **已解锁皮肤 ID 列表**（如 `[luffy_classic, zoro_classic]`） |
| `current_skins` | map<string,string> | {} | **各角色当前装备的皮肤 ID**（角色中文名 → 皮肤 ID，如 `路飞: luffy_classic`） |

### 3. 好感度系统

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `affinity` | map<string,int> | {} | **各角色好感度**（角色中文名 → 0-100，新角色默认 50） |
| `last_interaction` | map<string,string> | {} | **各角色最后互动时间**（角色中文名 → ISO 时间戳，用于每日衰减判断） |

### 4. 饱食度系统

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `satiety` | map<string,int> | {} | **各角色饱食度**（角色中文名 → 0-100，新角色默认 50） |
| `satiety_low_since` | map<string,string?> | {} | **饱食度低于阈值的起始时间**（角色中文名 → ISO，null 表示未触发） |

### 5. 背包

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `inventory` | map<string,int> | {} | **食物背包**（食物 ID → 数量，如 `meat: 3, fish: 1`） |

## profile.yaml 示例

```yaml
name: Alex
role: 路飞
scale: 0.4
default_provider: deepseek
created_at: 2026-07-07T10:30:00.0000000+08:00
last_login_at: 2026-07-07T15:43:15.0000000+08:00

# 经济系统
coins: 320
unlocked_skins:
  - luffy_classic
  - zoro_classic
  - luffy_gear4
current_skins:
  路飞: luffy_gear4
  索隆: zoro_classic

# 好感度
affinity:
  路飞: 75
  索隆: 45
last_interaction:
  路飞: 2026-07-07T15:42:00.0000000+08:00
  索隆: 2026-07-06T20:10:00.0000000+08:00

# 饱食度
satiety:
  路飞: 85
  索隆: 30
satiety_low_since:
  路飞: null      # 饱食度正常
  索隆: null      # 饱食度 30 > 阈值 20，未触发

# 背包
inventory:
  meat: 3
  fish: 1
  rice: 2
```

## 便捷方法（UserProfile.cs）

| 方法 | 用途 |
|---|---|
| `GetAffinity(role)` | 获取角色好感度（未设置返回 50） |
| `GetSatiety(role)` | 获取角色饱食度（未设置返回 50） |
| `GetCurrentSkin(role)` | 获取角色当前皮肤 ID（未设置返回空） |
| `SetCurrentSkin(role, skinId)` | 设置角色当前皮肤 ID |
| `GetInventory(foodId)` | 获取背包中食物数量 |
| `AddInventory(foodId, count)` | 增加背包食物 |
| `ConsumeInventory(foodId, count=1)` | 消耗背包食物（不足返回 false） |

## 用户注册表（users.yaml）

记录所有用户的元数据，与 `profile.yaml` 分离：

```yaml
users:
  - name: Alex
    created_at: 2026-07-07T10:30:00.0000000+08:00
    last_login_at: 2026-07-07T15:43:15.0000000+08:00
  - name: Bob
    created_at: 2026-07-05T14:20:00.0000000+08:00
    last_login_at: 2026-07-05T14:20:00.0000000+08:00
```

## 数据流

### 创建新用户

`UserService.CreateUser(name)`：
1. 检查用户名是否已存在
2. 创建 `user_data/users/<name>/` 目录
3. 初始化 `UserProfile`：
   - `Coins` = `pet_management.yaml` 的 `initial_coins`（默认 100）
   - `Role` = 当前默认角色（从 `ConfigService.Load().Role`）
   - `Scale` = 0.4
   - `DefaultProvider` = "local-klee"
4. `SkinService.InitDefaultSkins(profile)`：解锁所有 `is_default: true` 的皮肤并设为当前皮肤
5. 写入 `profile.yaml`
6. 加入 `users.yaml` 注册表

### 金币变化

| 场景 | 变化 |
|---|---|
| 新用户初始 | +100（`initial_coins`） |
| 购买皮肤 | -400 × 折扣（`SkinPrice × SkinDiscount`） |
| 购买食物 | -食物单价 × 数量 |

### 好感度变化

| 场景 | 变化 |
|---|---|
| 新角色初始 | 50（`initial_affinity`） |
| 聊天（每条消息） | +1（`Rewards.ChatPerMessage`） |
| 完成待办 | +2（`Rewards.TodoComplete`） |
| 喂食喜欢 | +8（`Rewards.FeedLoved`） |
| 喂食普通 | +5（`Rewards.FeedNormal`） |
| 喂食讨厌 | +1（`Rewards.FeedDisliked`） |
| 抚摸 | +1（`Rewards.Pat`） |
| 击掌 | +2（`Rewards.Highfive`） |
| 饱食度>80 加成 | ×1.2（`Rewards.SatietyHighBonus`） |
| 每日不互动 | -2/天（`Decay.AffinityLossPerDay`） |
| 饱食度<20 持续 2 小时 | -1/2小时（`Decay.SatietyLowAffinityLossMinutes`） |
| 静音状态 | -1/小时（`Decay.MutedAffinityLossPerHour`） |

### 饱食度变化

| 场景 | 变化 |
|---|---|
| 新角色初始 | 50（`initial_satiety`） |
| 喂食 | +食物的 `satiety_gain`（上限 100） |
| 自然衰减 | -10/6小时（`Decay.SatietyLossPer6h`，由 AffinityService 计时器附带处理） |

### 背包变化

| 场景 | 变化 |
|---|---|
| 购买食物 | +数量 |
| 喂食 | -1 |

## 衰减后台计时器

`AffinityService` 启动 `DispatcherTimer`（1 分钟/次），在 `App.OnStartup` 用户登录后调用 `Start()`：

```
每分钟 tick
  ↓
遍历所有角色：
  ├─ CheckDailyDecay：若 last_interaction 距今 ≥1 天，扣 AffinityLossPerDay × 天数
  ├─ CheckSatietyLowDecay：若 satiety < SatietyLowThreshold 且持续 ≥SatietyLowAffinityLossMinutes，扣 1
  └─ 若 App.IsMuted 且本次 tick 累计 ≥60 分钟，扣 MutedAffinityLossPerHour × 小时数
```

详见 [宠物管理.md](宠物管理.md) 的 AffinityService 部分。

## 好感度等级

定义在 `pet_management.yaml` 的 `levels` 字段（从高到低匹配，第一个满足 `min` 的等级生效）：

| 等级 | min | SkinDiscount | 描述 | AI 对话风格 |
|---|---|---|---|---|
| 挚友 | 80 | 0.7 | 专属台词 | 可非常亲密地称呼对方 |
| 亲密 | 60 | 0.8 | 表达亲近 | 可以亲近地交流 |
| 友好 | 40 | 0.9 | 主动关心 | 可以主动关心对方 |
| 认识 | 20 | 0.95 | 偶尔热情 | 偶尔可以热情一些 |
| 陌生人 | 0 | 1.0 | 冷淡称呼 | 保持礼貌的距离感 |

等级影响通过 `ChatOrchestrator.BuildDefaultSystemPrompt()` 注入系统提示，影响 AI 对话风格。

## 备份与迁移

`profile.yaml` 是纯文本 YAML，可直接复制备份。迁移到新机器时：
1. 复制 `user_data/users/<name>/` 整个目录到新机器
2. 在 `user_data/users.yaml` 注册表添加该用户条目
3. 启动应用，登录该用户即可恢复所有宠物管理数据

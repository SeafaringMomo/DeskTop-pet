# 助手管理数据库

说明助手养成数据（金币、好感度、饱食度、背包）与对话/待办数据的存储方式。

**核心结论**：养成数据（金币/好感度/饱食度/背包）存在 `profile.yaml`（YAML），便于查看与备份；对话与待办使用 SQLite。

## profile.yaml 字段

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `name` | string | - | 用户名（唯一标识） |
| `role` | string | 默认角色 | 当前角色显示名 |
| `scale` | double | 0.4 | 显示缩放 |
| `default_provider` | string | local-klee | 默认 AI Provider |
| `created_at` / `last_login_at` | string | - | 时间戳 |
| `coins` | int | 100 | 金币 |
| `affinity` | map<string,int> | {} | 各角色好感度（0-100） |
| `last_interaction` | map<string,string> | {} | 各角色最后互动时间 |
| `satiety` | map<string,int> | {} | 各角色饱食度 |
| `satiety_low_since` | map<string,string?> | {} | 饱食度<20 的起始时间 |
| `inventory` | map<string,int> | {} | 食物背包（食物 ID → 数量） |

皮肤相关字段（`unlocked_skins` / `current_skins`）与 `GetCurrentSkin` / `SetCurrentSkin` 已随皮肤系统移除。

## 好感度衰减计时器

[AffinityService](../Services/Core/AffinityService.cs) 使用 1 分钟 `DispatcherTimer`：

1. 每日不互动：每满 1 天扣 `decay.affinity_loss_per_day`。
2. 饱食度<20 持续 `satiety_low_affinity_loss_minutes` 分钟：每周期扣 1 点。
3. 静音状态：每累计 1 小时扣 `muted_affinity_loss_per_hour`。

扣款后必须更新 `LastInteraction[role]` 或 `SatietyLowSince[role]`，避免重复扣；饱食度恢复时清空 `SatietyLowSince[role]`。

## 好感度等级

等级表在 `config/gent_management.yaml` 的 `levels`：

| 等级 | 下限 | AI 对话风格（快捷） |
|---|---|---|
| 挚友 | 80 | 非常亲密 |
| 亲密 | 60 | 亲近 |
| 友好 | 40 | 主动关心 |
| 认识 | 20 | 偶尔热情 |
| 陌生人 | 0 | 保持礼貌距离 |

`skin_discount` 字段已移除，等级仅影响 AI 对话风格。

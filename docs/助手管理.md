# 助手管理

助手管理中控窗口，包含 4 个页签：商店、互动、喂食、状态。从助手右键菜单「助手管理」打开。

对应代码：[Windows/GentManager/GentManagerWindow.xaml.cs](../Windows/GentManager/GentManagerWindow.xaml.cs)。

## 商店（Shop）

[商店面板](../Windows/GentManager/Panels/ShopPanel.cs) 提供：

- **金币充值**：`+100` / `+500` / `+1000` 按钮，直接增加当前用户金币并保存档案。
- **食物购买**：列出全部食物（`config/foods.yaml`），点击「购买×1」扣金币、入背包。

原皮肤商城已随皮肤系统移除。喂食面板不再提供购买入口，统一到这里的「食物购买」。

## 互动（Interact）

[互动面板](../Windows/GentManager/Panels/InteractPanel.cs)：

- 抚摸 `pat`：+1 好感度，冷却 5 秒。
- 击掌 `highfive`：+2 好感度，冷却 30 秒。
- 玩耍 `play`：预留按钮，敬请期待。

互动只更新好感度状态，**不播放响应动画**。冷却剩余秒数每秒刷新，按钮在冷却中禁用。

## 喂食（Feed）

[喂食面板](../Windows/GentManager/Panels/FeedPanel.cs)：

- 展示当前角色饱食度与背包食物。
- 点「喂食」：扣背包食物 → 加饱食度 → 按角色偏好加好感度（饱食度>80 时 ×1.2）。
- 背包为空时提示「请到商店购买食物」。

食物购买按钮已移到商店页签。

## 状态（Status）

[状态面板](../Windows/GentManager/Panels/StatusPanel.cs) 展示：

- 当前角色
- 金币
- 好感度与等级
- 饱食度与状态（饥饿/饱腹）
- 等级对 AI 对话风格的影响（`GetSystemPromptHint`）

皮肤相关字段已移除。

## 主题

所有 Panel 通过 `IGentManagerPanel` 接口接收角色主题（来自 `static/<角色>/theme.yaml`），窗口 Tab 与 Panel 配色随角色切换。
